# Call QA

Контроль качества телефонных звонков: записи с АТС → распознавание речи (GigaAM, на процессоре) → оценка работы сотрудника по чек-листу моделью LLM → веб-интерфейс, отчёты XLSX/PDF, API. Все данные остаются на вашем сервере.

Свободное программное обеспечение: скачивайте, устанавливайте и дорабатывайте как угодно (лицензия MIT).

## Состав
- `app/` — веб-приложение, очередь, распознавание, оценка (Python, FastAPI, PostgreSQL).
- `deploy/` — установка на чистый сервер: Docker Compose, `install.sh`, офлайн-пакет, проверка. **Начните с [deploy/README.md](deploy/README.md).**
- `collector/` — автоматический сбор записей с АТС (FreePBX; другие АТС — адаптеры).
- `templates/` — примеры чек-листов и схема ответа модели.
- `tools/` — смена цветовой палитры (`palette.py`) и перерисовка иконок (`make_icons.py`).

## Быстрый старт
```bash
git clone https://github.com/azalor-zh/call-qa.git callqa && cd callqa/deploy
sudo ./install.sh --domain callqa.example.com --with-llm
./smoke-test.sh
```
Оценка звонков: встроенный Ollama (модели скачиваются в админке) или внешний OpenAI-совместимый API. Подробности — в `deploy/README.md`.
Пароль администратора создаётся случайным при установке и выводится в консоль (хранится в `deploy/.env`).

## Оформление
Логотипа в интерфейсе нет, в шапке только название. Цвета меняются одной командой: `python tools/palette.py --from magenta --to <ваша палитра> --apply` (палитры описаны в `tools/palette.py`). Свой логотип для PDF/Excel-отчётов — `app/static/brand/logo.png`.

## Статус
Версия 0.1.0. Протестировано на RHEL 10 (Docker CE, без GPU). Ubuntu, Podman, GPU и офлайн-пакет ещё не проверены.
